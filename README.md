# SCT_ML_2
# Customer Segmentation using K-Means Clustering

This project is completed as **Task 2** for the **SkillCraft Technology Machine Learning Internship**.

## Objective

Group retail store customers into different segments based on their purchase behavior using the **K-Means Clustering** algorithm.

## Dataset

* **Dataset:** Customer Segmentation Tutorial in Python
* **Source:** Kaggle
* **File Used:** `Mall_Customers.csv`

## Technologies Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Scikit-learn

## Features Used

* Annual Income (k$)
* Spending Score (1–100)

## Project Workflow

1. Imported the required libraries.
2. Loaded the dataset.
3. Selected Annual Income and Spending Score as features.
4. Used the **Elbow Method** to determine the optimal number of clusters.
5. Trained a K-Means model with **5 clusters**.
6. Assigned each customer to a cluster.
7. Visualized the customer segments with a scatter plot.

## Output

* Elbow Method graph
* Customer segmentation scatter plot
* Cluster labels added to the dataset

## How to Run

1. Open the notebook in Google Colab.
2. Upload `Mall_Customers.csv`.
3. Run all cells in order.
4. View the Elbow Method graph and customer segmentation plot.
